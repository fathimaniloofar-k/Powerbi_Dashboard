🥗 Nutrition Data Analysis Dashboard | Power BI

 📌 Project Overview

This project focuses on analyzing nutritional information of 10,000 food items using Microsoft Power BI.

The objective of this project is to explore the nutritional composition of different food categories, compare food items based on their nutritional values, and identify patterns in calories, protein, carbohydrates, fat, sugar, fiber, sodium, and cholesterol.

An interactive Power BI dashboard was developed to transform raw nutrition data into meaningful insights through visualizations, KPI cards, and interactive filters.


 📁 Dataset Description

The dataset contains 10,000 food records and 12 columns.

| Column | Description |
|---|---|
| Food_ID | Unique identifier for each food item |
| Food_Name | Name of the food item |
| Category | Food category |
| Calories_kcal | Calories in kcal |
| Protein_g | Protein content in grams |
| Carbohydrates_g | Carbohydrate content in grams |
| Fat_g | Fat content in grams |
| Fiber_g | Fiber content in grams |
| Sugar_g | Sugar content in grams |
| Sodium_mg | Sodium content in milligrams |
| Cholesterol_mg | Cholesterol content in milligrams |
| Nutrient_Density_Score | Nutritional density score |

 🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and visualization
- Power Query – Data cleaning and transformation
- DAX – Calculations and measures
- CSV – Dataset format

 📈 Dashboard Features

 1. Key Performance Indicators (KPIs)
The dashboard displays important nutritional metrics:

- Total Number of Foods: 10K
- Average Protein: 7.58 g
- Average Sugar: 7.12 g
- Average Calories: 191.65 kcal
- Average Fat: 9.38 g
- Average Nutrient Density Score: 4.80

2. Food Items by Category
A donut chart displays the distribution of food items across different food categories.

3. Top 10 Foods by Nutrient Density
Identifies the top 10 food items based on their nutrient density scores.

4. Top 10 Foods by Fat
Compares the 10 food items with the highest fat content.

5. Nutritional Comparison by Category
A line chart compares carbohydrates, calories, and fiber across different food categories.

6. Top 10 Foods by Protein
Highlights food items with the highest protein content.

7. Top 10 Foods by Sugar
Identifies food items with the highest sugar content.

🎛️ Interactive Filters

The dashboard includes two interactive slicers:

- Category Filter:  Allows users to select specific food categories.
- Food Filter:** Allows users to select individual food items.

These filters make it easier to explore and compare nutritional information dynamically.
